## Connective Tissue — where the system leaks

These are the seams that keep the project feeling like a library rather than a product. Each is unchanged from the prior re-audit **except #1, #5**, which are now closed.

1. **Audit trail was data, not UI.** DONE. `python -m src.cli.timeline <prod_id>` renders gate decisions, state transitions, and snapshots as a readable timeline.
2. **Asset lineage was recorded but not queryable.** DONE. `python -m src.cli.trace <sha256>` (or `<prod_id>`) renders references, generations, snapshots, branches, and merges as a DAG — ASCII tree or `--mermaid` for the browser.
3. **No health-check entry point.** DONE. `python -m src.cli.doctor <prod_id|--all>` (or with no prod_id, the project-scoped variant) emits a green/yellow/red report. With all three shipped, the observability triad is closed: a new user can run three commands on any production and understand exactly what it did, where its assets came from, and whether it is healthy.
4. **Branch comparison is data, not UI.** `ProductionService.branch_compare()` exists and returns a structured summary of two branch tips (per-branch counts, reviewer scores, divergence events since the common ancestor); nobody exposes it. Pain: the proposal-first loop ("fork at creative reframing, pick the best angle") is invisible — users can't see why one branch is better than another without reading JSON.
5. **No unified `production` CLI.** Subcommands are still `python -m src.cli.<name>`; no top-level `production run | timeline | trace | doctor | compare` entry. Pain: each new CLI command requires explaining the long form. (Smaller pain than an hour ago, because the long form is now well-documented across three sibling files.)
6. **No top-level `production run "<intent>"`.** Pain: the project's headline promise ("give it an intent, get a production") is demonstrated only by `demo_flow.py`, which is one-shot and synthetic. Tied to the runner gap.
7. **No runner drives the 26-stage pipeline.** State machine is in code; nothing walks it. Pain: every demo path is bespoke (`scripts/run_demo.py`, `examples/run_crew_demo.py`, `src/demo_flow.py`); a new user does not know which script to run.
8. **Plugin registry is not auto-discovered.** Pain: the kernel's plugin-blind claim is unobservable — to add a vertical today you edit kernel code.
9. **Web surface is 2 of 5 wireframes.** Pain: `Timeline view` and `Directors Canvas` are the two missing high-wonder views; their absence makes the audit trail and proposal-comparison flow invisible in the browser.
10. **End-to-end happy path is not test-protected.** Pain: `python -m src.demo_flow` runs; nothing asserts that every gate fires, every agent produces output, and the publish manifest validates.
