## Post-audit delta (2026-07-29, same evening)

While running the keystone through the dispatcher (`python -m src.cli run`), the 7 `tests/test_cli_main.py` cases that exercise the dispatcher itself turned up a bug in the dispatcher's own argument parser: `run_parser.add_argument("topic", "--topic", help=...)`. argparse treats both names as option strings (which must start with `-`) and raises `ValueError: invalid option string 'topic'` before any subcommand even runs — so `python -m src.cli timeline …` / `trace …` / `doctor …` / `compare …` all blew up with that same error. Fix: drop the `--topic` alias and keep `topic` as a plain positional in the dispatcher (matching `src/cli/run.py`'s positional shape). The dispatcher parser is only used for `--help` and validation; actual parsing happens in the delegated `run.main()` / `compare.main()` / etc.

After the fix:
- `python -m src.cli --help` lists all 5 subcommands (`timeline / trace / doctor / compare / run`).
- `python -m src.cli run --help` shows the full option set.
- `python -m src.cli run "CRISPR for sickle cell" --no-confirm --out <dir>` exits 0, writes 30 audit entries.
- 7/7 dispatcher tests + 7/7 run tests + 17/17 compare tests + all other suites: **600/600 green** (was 597 before the dispatcher fix; +3 because the dispatcher test failures also resolved).
